# ADR-0001: Record architecture decisions

- Status: accepted
- Date: 2026-09-30

## Context
The platform will grow over many PRs and several agents and people will work on it. Decisions
need to survive beyond chat threads.

## Decision
Record significant decisions as numbered ADRs in `docs/adr/` (context, decision, consequences).
Superseded ADRs are kept and marked as superseded.

## Consequences
Every PR that changes architecture adds or updates an ADR.
